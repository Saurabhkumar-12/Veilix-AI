# Veilix AI

### Uncover what app can access.

Veilix AI is an evidence-first AI-powered application permission intelligence platform that helps users understand what an application can access before they trust or install it.

Instead of blindly trusting AI-generated security claims, Veilix AI combines application evidence, Android permission metadata, deterministic risk analysis, and AI explanations to provide transparent and understandable permission insights.

---

## 🚀 Why Veilix AI?

Modern applications often request access to sensitive capabilities such as:

- 📍 Location
- 📷 Camera
- 🎤 Microphone
- 👥 Contacts
- 💬 SMS
- 📁 Storage
- 📡 Bluetooth
- 🔔 Notifications

The problem is that users often don't know:

> **Why does this application need this permission?**

Veilix AI answers that question using an evidence-first analysis approach.

### Our core principle

> **AI should explain security evidence, not invent security evidence.**
